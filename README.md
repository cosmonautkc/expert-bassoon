# Frontend Mentor – Testimonials grid section solution

This is my solution to the [Testimonials grid section challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/testimonials-grid-section-Nnw6J7Un7).
Frontend Mentor challenges help improve front-end skills by building realistic layouts and practicing modern CSS techniques.

## Overview

### The challenge

Users should be able to:

- View the optimal layout for the site depending on their device's screen size

## My process

### Built with

- Semantic HTML
- CSS custom design tokens
- Flexbox
- CSS Grid
- Mobile-first workflow

### What I learned

This was my second project using Grid, and my first time working with a more complex, asymmetric grid layout.

Key things I learned and reinforced:

- Using CSS Grid areas to control layouts across breakpoints
- Combining Grid for page layout with Flexbox for internal component structure
- Building layouts mobile-first using media queries for larger screen sizes
- Using CSS custom properties to keep spacing, colors, and typography consistent
- Managing uneven content heights without fixed dimensions

This project helped me feel much more confident working with Grid and mobile first responsive layout logic.
